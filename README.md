## Selected tools

- [`zsasa`](https://github.com/N283T/zsasa) — high-performance SASA calculation in Zig, with Python bindings.
- [`ztraj`](https://github.com/N283T/ztraj) — high-performance molecular dynamics trajectory analysis library.
- [`zdssp`](https://github.com/N283T/zdssp) — DSSP secondary-structure assignment implemented in Zig.
- [`mmcif-dict-cli`](https://github.com/N283T/mmcif-dict-cli) — CLI for querying mmCIF/PDBx dictionary definitions.
- [`ccd2rdmol`](https://github.com/N283T/ccd2rdmol) — lightweight library/CLI to convert PDB CCD files into RDKit molecules.

More tools and contribution notes are maintained on the [Dev page](https://n283t.github.io/ja/dev/).
